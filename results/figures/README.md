# results/figures/

Empty. Plots generated from committed data by committed scripts.

**Rules.**
1. Generated by script, never by hand or by screenshot-of-a-screen. A figure that cannot be
   regenerated cannot be corrected.
2. Every figure's filename carries its result ID or experiment ID.
3. Every figure states **which model produced it** in its legend — ideal circuit, microstrip,
   Momentum and measured are four different things (risk R-23).
4. Vector format (SVG/PDF) for anything heading to the seminar.
5. The colour convention for the six model types is fixed once in
   `seminar/asset_register.md` and used everywhere.
