# pcb/exports/

Empty — no PCB work has been done.

Gerbers, drill files, fabrication drawings, ODB++ — exactly as sent to the fabricator, never edited afterwards. Each export set in a dated subdirectory, so what was sent is always recoverable.

**Gate:** G9

**Exports are write-once.** They are the record of what was actually manufactured. If a revision
is needed, make a new dated subdirectory — never edit a set that has been sent.

Verify every export in an **independent viewer** before ordering, not only in the CAD tool that
produced it (gate G9). A CAD tool renders its own interpretation of the design; a third-party
viewer renders the file the fabricator will actually receive.
